Reproduce a result

Run from the repository root with Node.js 22 or newer. Keep Git history available for scripts that load pinned revisions. Use new output directories to preserve the recorded evidence.

Open the project

npm ci
npm run dev

Browse /docs/development.html on the Vite server. See README for setup and deployment; install browser test support with npx playwright install chromium.
