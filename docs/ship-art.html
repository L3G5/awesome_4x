Delivery contract & cost

import { shipImage } from '../src/ship-art.js';
shipImage(type, { color = '#76d7c4', ancient = false } = {})

  • Returns a transparent 512 × 320 PNG data URL. Supported classes: scout, colony, frigate, cruiser. Unknown classes use scout. Colors accept three- or six-digit hexadecimal; invalid colors use the default. No simulation state is read.
  • One lazy reusable offscreen WebGL2 renderer, with no animation loop, timer, asset loading or runtime network request. At most 24 portraits are retained in a least-recently-used cache, keyed by normalized class, color and heritage.
  • Geometry, materials and the 512 × 512 key-light shadow map are disposed after capture. Renderer render lists are cleared. GPU use is bounded by one antialiased 512 × 320 color/depth surface plus the current model, shadow map and programs; exact allocation depends on the browser.
  • One decoded RGBA portrait is 640 KiB; 24 simultaneously decoded portraits would be 15 MiB (15,728,640 bytes), excluding browser overhead and compressed data URL strings. The module stores only PNG strings; the browser controls image decoding and its own cache. Visible image elements may retain portraits beyond the module’s cache. No image pixels are retained in application arrays after rendering.
  • On WebGL unavailability or context loss, Canvas2D projects and shades the same native geometry. It preserves all four silhouettes and uses a single reusable 512 × 320 canvas. Its painter’s algorithm and flat lighting are less exact than WebGL depth testing and material shading.
  • Uncached work includes mesh generation, one static render and PNG encoding. The first WebGL request also compiles shaders. Measured timings below describe this browser and hardware only. Repeated requests return the cached string; arrange visible images on demand.

Verification snapshot

Chromium with SwiftShader, 28 October 2026: the first WebGL portrait took 137 ms; subsequent unique portraits took 70–76 ms. The eight Canvas2D variants took 8–24 ms each. Four hundred cached requests took about 1 ms; a separate 1,000-call check performed no PNG encoding. These are software-rendering measurements, not a promise for other devices.

All four classes had transparent corners and unclipped silhouettes. Repeated values and normalized colors reused the cache; the 24-entry limit evicted old entries, and regeneration produced identical PNG bytes. Forced WebGL unavailability and an explicit context-loss event both produced valid fallback portraits without creating another WebGL context.

GPU accounting across eight initial portraits and twenty further unique renders stayed constant after each capture: zero live geometry buffers, zero vertex arrays, five renderer-owned textures, three renderer-owned framebuffers and one shared depth program. All per-portrait shaders, geometry buffers and shadow textures were released. No animation-frame request occurred during rendering or the subsequent idle interval.
