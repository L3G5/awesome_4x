Production record

One visual language.
Five distinct subjects.

Method. Generated on 28 October 2026 with the built-in image_gen.imagegen tool. One new generation per distinct plate; five calls total. All first-pass images were selected after visual inspection. No reference images, external image assets, image edits, external service, CLI generation or API fallback were used. The tool does not expose an underlying model identifier in its result.

Art direction. Original painterly science-fiction illustration with ink/navy shadows, visible midtones, fine material detail and atmospheric scale. Amber commerce, ember industry and violet communion distinguish the civilizations. Blue-silver optics and sea-glass mineral light distinguish the expeditions. Central subjects remain legible at dossier size.

Authored foundation. Names, cultural descriptions and discovery premises come from src/content.js. The canonical narrative excerpts accompany each plate. These timeless illustrations depict no current game state, fleet count or chosen discovery outcome. Anonymous scale figures do not establish a new named leader likeness.

Delivery. The five original PNGs remain in the tool output directory recorded with each plate. Workspace assets are lossless WebP files, totaling 10,156,954 bytes (9.69 MiB), a 29.8% reduction from the source PNGs. Encoding changes the file format only: no resizing, cropping, compositing or retouching. Original and delivered images were decoded to RGBA and their SHA-256 hashes matched for every plate.

Lossless encoding

ffmpeg -i SOURCE.png -c:v libwebp -lossless 1 \
  -compression_level 6 -pix_fmt bgra OUTPUT.webp

Decoded-pixel verification

ffmpeg -v error -i IMAGE -map 0:v:0 -frames:v 1 \
  -c:v rawvideo -pix_fmt rgba -f hash -hash sha256 -

Presentation. The 320 × 112 dossier studies use CSS object-fit: cover and the recorded focal points; the delivery files retain the entire 3:2 composition. Load these narrative plates on demand in their dossiers or discoveries, rather than downloading all five at game startup. The /art/ paths are served by the project’s public-assets directory. This artbook uses relative file links and no external dependencies.
