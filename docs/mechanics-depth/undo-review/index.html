Source review and limits

Command execution commits a cloned candidate only on success; changed zero-order commands receive history while selection and language do not. Whole snapshots restore RNG, knowledge, logs, counters and escrow. Persistence releases optional history before saving the current campaign and rejects stale exact-state markers. The UI closes obsolete dialogs, validates restored selections and contexts, preserves current language, and supplies Undo within report/conclusion modals. End Cycle clears history on success rather than depending on a turn-number change.
